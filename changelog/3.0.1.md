This is a small patch update in preparation for the next story release ✨

- The game can now **download and apply small updates remotely** without updating the app. This is only used to fix minor dialogue errors. Don't worry, if an update fails, you'll still be able to play the game.
- The game now **detects when a new update is available**. I don't know how I managed to **forget** this before release!

- Added an **important message** to the main menu 🍉

- The game **no longer freezes** when failing to load an **ad** to unlock new beads.
- The ad loading text **is now translated** correctly.
- The load button in the bracelet studio **is now translated** correctly.
- Fixed some typos.
- Fixed a bug that sometimes caused ads to appear twice.
